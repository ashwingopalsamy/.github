# security

Please don't report a vulnerability in a public issue.

## how to report

Open the repository's **Security** tab and choose **Report a vulnerability**. That starts a private advisory only I can see. If the button isn't there, email hello@ashwingopalsamy.in with the repository, the affected version or commit and the steps to reproduce.

## what to expect

I acknowledge reports within 7 days (best effort, no SLA). I agree a disclosure date with you before anything goes public. There is no bug bounty.

## scope

I support the latest release, or `main` where there are no releases. Read the repository's README first, because behaviour it documents on purpose is not a vulnerability. Reports without a working reproduction are closed.
